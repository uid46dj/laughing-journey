# VALÉ — Obsidian No. 01

A Vite + React landing page for a premium, limited-edition writing instrument. The pen is rendered in CSS with a subtle 3D pointer inspection and GSAP-powered entrance/scroll animations.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Stack

- React + Vite
- GSAP + ScrollTrigger
- CSS 3D product illustration, responsive layout, and reduced-motion support
